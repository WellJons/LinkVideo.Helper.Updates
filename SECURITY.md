# Security

Этот репозиторий содержит только публичные артефакты обновления LinkVideo.Helper.

Исходный код, учётные данные, VPN-backup и внутренние данные LinkVideo здесь не публикуются.

Каждый полный установщик и патч должен быть опубликован через автоматизированный workflow из приватного репозитория и иметь SHA-256 в `update-manifest.json`.
