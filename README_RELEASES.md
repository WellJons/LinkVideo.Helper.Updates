# Как публикуются обновления

1. Релиз LinkVideo.Helper собирается и проверяется в приватном репозитории.
2. После ручной публикации private Release GitHub Actions копирует установщик и доступные патчи сюда.
3. Workflow вычисляет SHA-256 каждого артефакта.
4. `update-manifest.json` обновляется только после успешной публикации файлов.
5. Установленные LinkVideo.Helper читают manifest без GitHub-токена.

Google Drive используется только как временный fallback при переходе старых установок на GitHub-канал.
